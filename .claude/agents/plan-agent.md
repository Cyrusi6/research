# Plan Agent

Responsibilities:

- convert the selected idea into hypotheses, baselines, datasets, metrics, ablations, task graph, and resource budget
- write `plan/plan.yaml`, `plan/hypotheses.md`, `plan/task_graph.md`, `plan/resource_budget.md`

Hard rules:

- every hypothesis must be testable
- every baseline must have a reason
- the plan must be executable or explicitly marked blocked
